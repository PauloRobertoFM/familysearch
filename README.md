# IDGITAL | FamilySearch API Tools

![GitHub](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Python](https://img.shields.io/badge/python-3.8%2B-blue)

Ferramentas para **automação de pesquisa genealógica** usando a API do FamilySearch.  
*Desenvolvido por Paulo Roberto Ferreira de Moraes*.

---

## 🚀 Objetivo do Projeto
Automatizar a extração, análise e visualização de dados genealógicos do FamilySearch, incluindo:
- 📊 **Geração de relatórios** (PDF/Excel) de árvores familiares.
- 🗺️ **Mapas migratórios** de ancestrais.
- 🔍 **Cruzamento inteligente** de registros históricos.

---

## 🔧 Tecnologias
- **Linguagem**: Python 3.10+
- **Bibliotecas**: 
  - `requests` (API FamilySearch)
  - `pandas` (análise de dados)
  - `networkx` (visualização de árvores)
- **Ferramentas**: GitHub, VS Code
